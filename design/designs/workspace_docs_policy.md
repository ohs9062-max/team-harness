# 워크스페이스 규칙 문서 작성과 이관

AGENTS.md와 CLAUDE.md에는 지금 유효한 규칙만 명령문으로 쓴다. 경위, 사례, 폐기된 규칙, 사용자 원문 인용, 날짜별 사고 기록은 `docs/archive/AGENTS_이관_<YYYYMMDD>.md`로 옮긴다. 본문에는 해당 절을 가리키는 `(경위: docs/archive/AGENTS_이관_<YYYYMMDD>.md §<절>)` 한 줄만 남긴다.

각 문서의 상한은 기본 300줄이며 `TH_DOCS_MAX_LINES`로 설정한다. 이관할 때 내용을 지우지 않고 옮기기만 한다. 현재 유효한 규칙 문장 자체는 본문에 남긴다. 300줄 이하로 줄일 수 없다면 안전하게 줄일 수 있는 만큼만 옮기고 이유를 기록한다.
