# 전역 자동 적용

사용자가 th cord와 ths만 사용해도 실행 관찰과 이력 조회가 적용되어야 한다.

- 이미 전역 적용: 기존 hook과 공유 유지보수.
- 실행 후 관찰: 동일 사용자의 프로세스와 환경을 읽어 출처를 복원하고 색인한다. 원본 등록부와 실행 제어는 변경하지 않는다.
- 실행 전 가로채기: 다음 단계에서 PATH 앞 shim을 두며 처음에는 판정만 기록하는 관찰 모드로 운영한다.
- 명시 명령: ths, th-db, th-why로 조회한다.

예산 초과는 경고 후 실행하고 상한 대기가 30분을 넘으면 inbox에 알린다. 반드시 실패할 지시서 오류만 실행 전 정지한다. 같은 일의 반복 실패 2회에 정지하고 실행 깊이를 제한한다. 관찰로 편입된 작업은 자동 재실행하지 않으며 세션별 차단기는 처음에는 기록만 한다.

1차는 실행 후 관찰, 상태 DB와 코디네이터 자동 조회다. 실행 전 제어는 다음 단계다. 롤백 기준은 `checkpoint-20261112-pre-global` 태그다.
